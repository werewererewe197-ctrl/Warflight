# Warflight — воздушные бои 1939–1945

Браузерная мультиплеерная 2D-игра о воздушных боях Второй мировой с видом сбоку.
Энергетический бой, сваливание и штопор, повреждения по частям, катапультирование и бой пешком,
наземная техника, четыре режима, боты трёх уровней и прокачка в ангаре.

Графика целиком процедурная (рисуется на Canvas), названия самолётов и игры вымышленные.

## Запуск

Нужен Node.js 18+ (для автотестов — Node.js 22.12+).

```bash
npm install && npm start
```

Откройте http://localhost:3000. Порт можно сменить: `PORT=8080 npm start`.

### Игра по локальной сети

1. Запустите сервер на одном компьютере (`npm start`). В консоли будут адреса вида
   `в локальной сети: http://192.168.1.10:3000`.
2. Остальные игроки (ПК или телефоны в той же Wi-Fi-сети) открывают этот адрес в браузере.
3. Если не открывается, разрешите входящие подключения к порту 3000 в брандмауэре
   (Windows: «Разрешить приложение через брандмауэр» → Node.js).

### Хостинг на Render

1. Загрузите репозиторий на GitHub.
2. На https://render.com: **New → Web Service**, выберите репозиторий.
3. Build Command: `npm ci --omit=dev` (тестовые зависимости серверу не нужны), Start Command: `npm start`. Порт Render передаёт через `PORT`, сервер его подхватывает.
4. Health Check Path: `/health`.
5. Environment: `TRUST_PROXY=1` — Render проксирует запросы, без этого все игроки будут выглядеть как один IP и упрутся в лимит подключений.
6. WebSocket работает поверх того же адреса (`wss://<имя>.onrender.com/ws`), отдельно настраивать ничего не нужно.

На бесплатном тарифе диск временный, поэтому профили в `data/profiles.json` сбрасываются при перезапуске.
Чтобы они сохранялись, подключите Persistent Disk и укажите путь: `PROFILES_FILE=/var/data/profiles.json`.

### Хостинг на VPS (Ubuntu)

```bash
sudo apt install -y nodejs npm   # или Node 20 через nodesource
git clone <ваш-репозиторий> warflight && cd warflight
npm ci --omit=dev
sudo npm i -g pm2
PORT=3000 TRUST_PROXY=1 pm2 start server/index.js --name warflight
pm2 save && pm2 startup
```

Для домена и HTTPS поставьте nginx перед игрой (WebSocket требует заголовков Upgrade):

```nginx
server {
  server_name game.example.com;
  location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $remote_addr;
  }
}
```

После этого выпустите сертификат: `sudo certbot --nginx -d game.example.com`.

## Управление

| ПК | Действие |
|---|---|
| W / S | газ больше / меньше (плавно 0–100%) |
| A / D | поворот носа против / по часовой стрелке |
| M | включить/выключить управление мышью (нос следует за курсором) |
| Shift | форсаж (греет двигатель, при перегреве отключается) |
| Space / ЛКМ | стрельба |
| B | бомба |
| R / ПКМ | ракета |
| F | переворот на спину (два нажатия подряд дают бочку), G — автопереворот |
| E | катапультироваться; пешком на своём аэродроме — взлететь |
| Enter | чат (Shift+Enter — только команде) |
| Tab | таблица счёта, Esc — пауза/выход |

Пеший пилот: A/D — бег, W — прыжок, мышь и ЛКМ — стрельба, K — сдаться.

На телефоне в самолёте: слева джойстик (нос поворачивается туда, куда он отклонён) и над ним кнопка
катапульты; справа большая кнопка огня, вокруг неё бомба, ракета, форсаж и переворот (на кнопках
бомбы и ракеты показан остаток), у правого края ползунок газа. Автопереворот на телефоне включён.

Пеший пилот на телефоне управляется двумя джойстиками: левый — движение (влево/вправо — бег,
вверх — прыжок), правый — направление стрельбы, отклонение стика открывает огонь. Когда можно взлететь
или возродиться, появляется пульсирующая кнопка с самолётом. Сверху справа — таблица счёта, чат и меню.

## Механика

- **Физика полёта** (`shared/physics.js`): тяга пропорциональна удельной мощности прототипа (л.с./кг), подъёмная
  сила ∝ v² и углу атаки, сопротивление (паразитное, индуктивное, на больших углах, волновое выше Vne), гравитация.
  Ручка задаёт угол атаки; он ограничен перегрузкой `gmax`, поэтому на большой скорости поворот шире, а лучший
  разворот — на «угловой» скорости. Нос разгоняется с инерцией, которая растёт с массой (тяжёлые самолёты
  вялее). Закритический угол атаки на малой скорости или слишком малая скорость дают срыв, а если держать
  ручку — штопор; из него выходят, отпустив ручку. При наборе высоты скорость падает, в пикировании растёт,
  но выше Vne резко растёт сопротивление, рули «каменеют», а при превышении на 15% разрушаются крылья.
  Бесконечного вертикального подъёма нет ни у одного самолёта, даже с прокачанным двигателем и форсажем.
- **Масштаб мира**: игра — аркада с ускоренным временем (примерно ×5) и уменьшенным миром: 1 игровая
  единица ≈ 2,22 м. Скорость на приборах — в км/ч (ед/с × 1,6), высота — в метрах (ед × 2,22).
- **Земля и вода**: удар на скорости смертелен. Касание на малой скорости — посадка; жёсткая посадка
  (большая вертикальная скорость или касание на ~1,5–1,85 Vs) повреждает крылья и двигатель. На своём аэродроме
  на малой скорости самолёт чинится и перезаряжается. Посадка на воду на малой скорости разбивает самолёт,
  но пилот выживает и плывёт.
- **Повреждения по частям**: двигатель (дымит, теряет тягу, может заглохнуть), крылья (самолёт тянет,
  меньше подъёмной силы, при полном разрушении крыло отваливается), хвост (хуже управление), бак (пожар;
  потушить его можно быстрым пикированием). Каждое повреждение видно на модели.
- **Оружие**: пулемёты, пушки, бомбы, ракеты, у бомбардировщиков и некоторых штурмовиков бортовые стрелки.
  Стволы перегреваются, при длинной очереди растёт разброс («отдача»), боезапас ограничен.
- **Пилот на земле**: катапультирование, парашют, бег, прыжок, автомат. Пилот может сбивать низколетящие
  самолёты, дойти до своего аэродрома и снова взлететь. Возможен и вариант с таймером возрождения,
  это настраивается в лобби. Падение с высоты без парашюта ранит или убивает.
- **Честный счёт**: катапультирование или выход из матча после попаданий врага засчитывает ему фраг.
  Огонь по своим настраивается в лобби (по умолчанию выключен).
- **Наземные объекты**: штабы, ангары, разрушаемые здания, ПВО (стреляет по самолётам с упреждением),
  артиллерия, танки (в режиме баз приходят волнами). Объекты принадлежат командам, их уничтожение даёт очки;
  нейтральные здания разрушаются, но очков и опыта не дают. Штаб — укреплённый бункер (пулемёты почти
  бесполезны, бомбы наносят 35% урона).
- **Облака** скрывают самолёт: врага в облаке нет на мини-карте, боты теряют цель.

### Режимы

1. **Deathmatch** — каждый сам за себя.
2. **Team Deathmatch** — две команды, очки за сбитых.
3. **Уничтожение баз** — у команд есть штаб, ПВО, артиллерия и танки. Побеждает тот, кто уничтожит
   вражеский штаб (по времени — у кого штаб целее).
4. **Battle Royale** — одна жизнь, зона сужается, выживает последний.

### Карты

- **Коралловый архипелаг** (10 км): море с островами.
- **Поля и город** (13 км): холмы, река и город.
- **Горный перевал** (15 км): высокие хребты, нужно набирать высоту.

Края карты ограничены: за границей зоны боя через 3 секунды самолёт начинает получать урон.

### Нации и самолёты

США, СССР, Великобритания, Германия, Япония. У каждой нации по три самолёта: истребитель (ранг 1,
открыт сразу), штурмовик (ранг 2) и бомбардировщик (ранг 3). Названия вымышленные, но характеристики
сведены с прототипами (см. раздел «Реалистичность» в AUDIT_REPORT.md). Все параметры лежат в
`shared/planes.json`: `vmax` (ед/с, ×1,6 = км/ч), `vstall`, `vne` (предел пикирования), `gmax` (предельная
перегрузка), `mass` (т — инерция и таран), `thrust` (удельная тяга ≈ 120 × л.с./кг прототипа), `turn`
(предельная угловая скорость носа), `boost` (форсаж), прочность, броня, вооружение, боезапас, стрелки.

### Прокачка

За матч начисляются опыт и деньги (деньги = опыт): за сбитых, пилотов, вражеские наземные цели, урон и победу.
В **ангаре** самолёты своей нации открываются по порядку рангов, на каждый ставятся улучшения до 3 уровней.
Эффект одного уровня (`UPGRADE_EFFECTS` в `shared/constants.js`, показывается в ангаре): двигатель +5% тяги,
броня +8% прочности и +3 п.п. брони, урон +6%, боезапас +20% патронов (+10% ракет), точность −15% разброса и отдачи.
Профиль хранится на сервере в `data/profiles.json` по анонимному токену из localStorage (на сервере — только
хеш токена), копия кешируется в браузере. Открыть все самолёты — 27 500 ¤ (≈50 матчей), всё с улучшениями —
185 000 ¤ (≈340 матчей по 8 минут).

### Сетевая модель

- Сервер авторитарен: клиент шлёт только ввод (номер, тангаж, газ, кнопки) 30 раз в секунду.
  Физику, стрельбу, попадания и урон считает сервер: ровно 30 тиков/с (цикл по накопленному времени,
  без дрейфа `setInterval`) с двумя подшагами физики.
- Снапшоты рассылаются 15 раз в секунду. Выстрелы передаются событиями, клиент рисует трассеры сам.
- Свой самолёт (или пилот) клиент **предсказывает** той же функцией физики. Получив снапшот с номером
  последнего обработанного ввода, он берёт серверное состояние, переигрывает неподтверждённые вводы
  (**reconciliation**) и плавно гасит разницу.
- Чужие объекты **интерполируются**. Часы клиента синхронизируются с тиками сервера по наименее
  задержанным снапшотам, задержка интерполяции подстраивается под джиттер сети (100–400 мс), скорость
  «отрисовочного» времени корректируется плавно (±10%), при задержке снапшота — экстраполяция до 150 мс.
- **Компенсация лага**: во вводе клиент сообщает, какой тик сервера он видит на экране; пули игрока
  проверяются по позициям целей в этом тике (история 1 с, не дальше 500 мс назад). Поэтому попадание
  «в упреждение» засчитывается и при пинге 150–300 мс.
- **Обрыв связи**: при разрыве без закрывающего кадра (пропал интернет, уснул телефон) сервер держит место
  игрока 30 с; клиент переподключается сам и возвращается в тот же матч. Вкладка, закрытая штатно, выходит сразу.
  Если ввод не приходит 300 мс (вкладка в фоне), сервер подставляет нейтральный ввод — без стрельбы.

### Защита от читов и безопасность

- Позиция, скорость, попадания и урон никогда не принимаются от клиента.
- Скорострельность задают серверные таймеры оружия, боезапас и перегрев тоже считает сервер.
- Очередь ввода ограничена: за тик обрабатывается один ввод, лишние отбрасываются, поэтому ускорить
  своё время невозможно (спидхак).
- Ввод санируется (диапазоны, типы). После каждого шага проверяются скорость и координаты.
- До `hello` сервер не выполняет никаких команд. Без действительного токена — гостевой вход: только стартовые
  самолёты, прогресс не сохраняется. Один токен — одно подключение (вторая вкладка перехватывает сеанс).
- Лимиты: сообщения и чат, подключения с IP (одновременно и за 10 с), создание лобби (раз в 2 с), новые
  профили с IP в час, общее число лобби. За флуд соединение разрывается.
- HTTP раздаёт только `client/` и `shared/` (обход путей закрыт), отдаёт CSP и `nosniff`.
  Токены в файле профилей хранятся только как SHA-256.
- Кикнутый игрок не может вернуться в лобби 5 минут.
